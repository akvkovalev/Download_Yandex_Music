[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Yandex Music](https://img.shields.io/badge/Yandex-Music-red.svg)](https://music.yandex.ru)

Инструмент для синхронизации и скачивания плейлистов из Яндекс Музыки на локальный диск.

## ✨ Возможности

- 🔐 Автоматическая авторизация через Device Flow (токен сохраняется локально)
- 📀 Синхронизация всех плейлистов пользователя
- ⬇️ Скачивание треков в высоком качестве (MP3 320 kbps)
- 🔄 Отслеживание изменений (новые/удалённые треки)
- 💾 Возобновление прерванной загрузки
- 📁 Организация файлов по папкам плейлистов
- 📊 Экспорт структуры библиотеки в JSON

## 📋 Требования

- Python 3.8 или выше
- Аккаунт Яндекс Музыки (для высокого качества рекомендуется подписка Plus)

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/Download_Yandex_Music.git
cd Download_Yandex_Music

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/Mac
source .venv/bin/activate
pip install -U yandex-music
python start.py
```
При первом запуске автоматически:

Откроется браузер со страницей авторизации

Будет показан код для подтверждения

Токен сохранится в yandex_token.json

Начнётся синхронизация всех плейлистов

### Структура хранения
После синхронизации файлы будут организованы так:

```text
yandex_music_library/
├── yandex_token.json          # Токен авторизации
├── sync_metadata.json         # Метаданные синхронизации
├── library_structure.json     # Структура библиотеки
└── playlists/
    ├── 3_Мне нравится/
    │   ├── Artist - Song 1.mp3
    │   └── Artist - Song 2.mp3
    ├── 1032_9/
    └── 1040_Такси/
```
### Настройка качества
По умолчанию используется 320 kbps. Изменить можно в файле start.py:

```python
sync = YandexMusicSync(
    base_dir="yandex_music_library",
    delay=1,        # Задержка между запросами (секунды)
    bitrate=320     # 64, 192, 320 или 0 для lossless FLAC
)
```
| Битрейт  | Качество | Формат | Требования      |
|----------|----------|--------|-----------------|
| 64       | Низкое   | AAC    | -               |
| 192      | Среднее  | AAC    | -               |
| 320      | Высокое  | MP3    | -               |
| 0        | Lossless | FLAC   | Подписка Plus   |

### 📄 Формат файла токена
При авторизации создаётся файл `yandex_token.json`:

```json
{
    "access_token": "y0__...",
    "refresh_token": "...",
    "expires_in": 31536000,
    "token_type": "bearer",
    "created_at": 1734567890.1234567
}
```
| Поле          | Описание                                  |
|---------------|-------------------------------------------|
| `access_token`| Основной токен для доступа к API          |
| `expires_in`  | Время жизни токена в секундах (365 дней)  |
| `created_at`  | Временная метка создания токена           |

**Важно:** Никогда не публикуйте этот файл и не добавляйте его в Git!

### 🔄 Синхронизация
При каждом запуске скрипт:

✅ Скачивает только новые треки

🗑️ Удаляет локальные файлы, которых больше нет в плейлисте (если `delete_removed=True`)

💾 Сохраняет прогресс в sync_metadata.json

📊 Выводит статистику синхронизации

## 🛠️ Устранение проблем

| Проблема | Решение |
|---|---|
| **Ошибка авторизации** | 1. Удалите файл `yandex_token.json`. <br> 2. Запустите скрипт заново: `python start.py`. |
| **Прерванная загрузка** | Просто запустите скрипт снова. Загрузка продолжится с места остановки. |
| **Нет доступа к высокому качеству** | Убедитесь, что у вас активна подписка Яндекс Музыки Plus. |
